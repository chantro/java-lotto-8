# java-lotto-precourse
## 요구사항 요약
- 로또 번호 범위: 1~45
- 1장에 중복 없는 숫자 6개
- 당첨: 6개 + 보너스 1개
- 등수/금액:
    - 1등: 6개 / 2,000,000,000원
    - 2등: 5개 + 보너스 / 30,000,000원
    - 3등: 5개 / 1,500,000원
    - 4등: 4개 / 50,000원
    - 5등: 3개 / 5,000원
- 로또 가격: 1,000원
- 수익률: **소수점 둘째 자리에서 반올림 → 첫째 자리까지 표기** (예: 62.5%)
- 예외 발생 시: `IllegalArgumentException`, 메시지는 반드시 `[ERROR]`로 시작, **그 지점부터 재입력**

---

## 아키텍처 개요
- `InputView`: 입력(금액/당첨/보너스), 검증
- `OutputView`: 발행번호/통계/수익률 출력
- `Lotto`: 번호 6개 도메인(정렬/중복/범위 불변식)
- `WinningLotto`: 당첨번호(6) + 보너스(1) 검증
- `LottoGame`: 매칭/등수 집계(순수 계산)
- `LottoPrize`: 등수/금액/매핑 로직

## 기능 목록 (체크리스트)
### 입력 & 검증
- [x] (I-01) 구입 금액 입력 받기
    - [x] 금액이 숫자가 아니면 `[ERROR] 숫자 형식이 아닙니다.`
    - [x] 음수/0이면 `[ERROR] 양수로 입력해 주세요.`
    - [x] 1000원 단위 아님 `[ERROR] 1000원 단위로 가격을 입력하세요.`
    - [x] 유효 시 발행 개수 = 금액/1000
    - [x] 실패 시 해당 단계부터 재입력
- [x] (I-02) 당첨 번호 입력 받기 (쉼표 구분, 공백 허용)
    - [x] 6개, 1~45, 중복 금지 유효성, 오름차순
    - [x] 실패 시 해당 단계부터 재입력
- [x] (I-03) 보너스 번호 입력 받기
    - [x] 숫자/1~45 범위/당첨 번호와 중복 금지
    - [x] 실패 시 **보너스만** 재입력

### 도메인
- [x] (D-01) `Lotto`: 불변(정렬/중복/범위) 보장
- [x] (D-02) `WinningLotto`: 보너스 범위 + 중복 검증
- [x] (D-03) `LottoPrize`: 등수/금액/매핑 (6→1등, 5+보너스→2등, 5→3등, 4→4등, 3→5등, else→꽝)
- [x] (D-04) `LottoGame`: 발행 로또 vs 당첨 결과 집계 (부작용 없이 새 맵 반환)

### 출력
- [x] (O-01) 발행 번호 개수 및 각 번호 출력
- [ ] (O-02) 당첨 통계 표 출력(5등→1등 순서, 0개도 표기)
- [ ] (O-03) 총 수익률 출력 (공백/문장부호 일치)

### 테스트
- [ ] (T-01) `LottoTest`: 개수/범위/중복/정상 생성(+ 불변성)
- [ ] (T-02) `WinningLottoTest`: 보너스 중복/범위
- [ ] (T-03) `LottoPrizeTest`: 매핑 케이스
- [ ] (T-04) `LottoGameTest`: 등수별 카운트, 중복 집계 없음
